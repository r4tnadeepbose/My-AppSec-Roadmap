# My Application Security Roadmap

A personal, learning-based Application Security roadmap by **Ratnadeep Bose**, inspired by **Semgrep Academy Application Security (Levels 1–3)**.

This project consolidates my understanding of Application Security concepts, activities, tools, and practices into a practical, progressive roadmap—from foundational activities to continuous improvement.

> **Important:** This is a personal learning-based project and **not** an official Semgrep Academy framework or publication.

## Learning Foundation & Certificates

- Semgrep Academy – Application Security Course 1 (Level 1): [**Certificate**](https://academy.semgrep.dev/certificates/vth81up4wt)
- Semgrep Academy – Application Security Course 2 (Level 2): [**Certificate**](https://academy.semgrep.dev/certificates/joc8lqqxsv)
- Semgrep Academy – Application Security Course 3 (Level 3): [**Certificate**](https://academy.semgrep.dev/certificates/o0pqqdkla2)

## Overview

The roadmap is presented as a **single-page web experience** (`index.html`) where you can view:

- **My Roadmap**: personal project context, learning foundation, roadmap structure, and reflections
- **Overview**: end-to-end Application Security program roadmap flowchart
- **Phase 0 – Discover**: assessment and foundation
- **Phase 1 – Establish**: foundational security controls
- **Phase 2 – Operationalize**: repeatable AppSec practices
- **Phase 3 – Integrate**: DevSecOps and modern security integration
- **Phase 4 – Govern**: policies, standards, and incident response
- **Phase 5 – Optimize**: continuous improvement

## Features

- Single-page navigation with tabs (no separate page loads required)
- Interactive Mermaid flowcharts for the overview and each phase
- Zoom in/out and reset controls
- Pan controls and **drag-to-pan** (click and drag the diagram area)
- **Fullscreen** mode for each flowchart view
- Dark, black/green-themed UI

## Getting Started

1. Open [`index.html`](./index.html) in a modern web browser.
2. Use the top navigation tabs to switch between **My Roadmap**, **Overview**, and **Phase 0–5**.
3. In flowchart views:
   - Use `+`, `−`, and `Reset` to zoom
   - Use arrow buttons or drag the diagram to pan
   - Click **Fullscreen** for a larger view (`Esc` to exit)

## Notes

- The flowcharts are rendered in the browser using [Mermaid](https://mermaid.js.org/) loaded from a CDN, so an internet connection may be required for diagram rendering.
- This roadmap reflects a personal interpretation and organization of learning from Semgrep Academy Levels 1–3.
